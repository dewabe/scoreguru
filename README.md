### ScoreGuru – Pisteytyssäännöt

ScoreGuru-sovellus käyttää seuraavaa pisteytysjärjestelmää ennustusten arviointiin:

1. **Kotijoukkueen maalimäärä oikein:** +1 piste  
2. **Vierasjoukkueen maalimäärä oikein:** +1 piste  
3. **Ottelun voittajan oikein ennustaminen (kotivoitto, vierasvoitto tai tasapeli):** +1 piste  
4. **Tarkan tasapelituloksen oikein ennustaminen (esim. 2–2):** +1 piste  

**Esimerkki:**  
- **Veikkaus:** Kotijoukkue 4 – Vierasjoukkue 2  
- **Toteutunut tulos:** Kotijoukkue 4 – Vierasjoukkue 2  
  - Kotijoukkueen maalimäärä oikein: **+1 piste**  
  - Vierasjoukkueen maalimäärä oikein: **+1 piste**  
  - Voittaja oikein: **+1 piste**  
  **Yhteensä:** 3 pistettä  

Tarkka tasapelitulos tuo lisäpisteen, mutta ylimääräistä bonuspistettä ei jaeta. Näin ollen maksimi pistemäärä on 4.
